## Описание проекта
Данный проект представляет собой эмулятор командной строки, работающий в режиме REPL (Read-Eval-Print Loop). Эмулятор симулирует работу в терминале UNIX-подобной операционной системы. Логика файловой системы полностью изолирована и загружается из виртуальной модели в формате JSON.

### Реализованные команды:
* `ls` — вывод содержимого текущей директории VFS.
* `cd <путь>` — смена текущей директории виртуальной файловой системы.
* `history` — вывод списка всех успешно введенных команд за текущую сессию (Индивидуальное требование).
* `tree` — рекурсивный вывод структуры каталогов в виде дерева с дефисами (Индивидуальное требование).
* `head <файл>` — вывод первых 10 строк содержимого виртуального текстового файла (Индивидуальное требование).
* `exit` — штатное завершение работы эмулятора.

## Требования к окружению
* Python версии 3.10 или выше.
* Операционная система: Windows / macOS / Linux.

## Инструкция по запуску
Для запуска эмулятора необходимо передать обязательные аргументы командной строки: путь к JSON-файлу виртуальной файловой системы (`--vfs`) и путь к стартовому скрипту (`--script`).

```bash
python src/main.py --vfs src/vfs.json --script src/start.sh
```

## Запуск автоматических тестов
Для проверки работоспособности парсера команд и обработки комментариев используются юнит-тесты:

```bash
python -m unittest discover -s tests
```
